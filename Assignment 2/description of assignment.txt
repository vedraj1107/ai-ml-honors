# Employee Management System (CSV CRUD)

~A menu-driven Python program that performs CRUD operations on employee table stored in a CSV file.
~built with a single class.

## Features
1. Add a new employee
2. View all employees
3. Search an employee by ID
4. Update an employee's details
5. Delete an employee

## How it works
- The `Employee` class manages all operations on `employee.csv`.
- On first run, the CSV file is created automatically with the columns `id, name, dept, salary`.
- A `while True` menu lets the user pick an option until they choose Exit.
- Update and delete read the whole file into a list, change the list, and write it back.

## Concepts used
- **Classes and methods:** all operations are grouped inside the `Employee` class.
- **File handling:** `"r"` to read, `"w"` to write, `"a"` to append.
- **csv module:** `csv.reader` and `csv.writer` for reading and writing rows.
- **CRUD:** Create, Read, Update, Delete.
- **Menu-driven program:** `while True` with `if/elif` and `break`.

## Project structure
- `employee_basic.py`: main program
- `employee.csv`: data file, created automatically

## Run
python employee_basic.py
